# neko-mind 🐱🧠

> a rust-powered heart for your AI companion

Core engine for the **neko** AI companion project. Handles the heavy lifting — inference, memory retrieval, personality state — while staying fast and lightweight.

Built with Rust for performance and reliability, designed to be embedded into a Python application via FFI.

## Features (WIP)

- [ ] Personality state machine
- [ ] Long-term memory with vector retrieval
- [ ] Efficient tokenizer wrappers
- [ ] Python bindings (PyO3)

## Usage

```toml
[dependencies]
neko-mind = { git = "https://github.com/Aumnertic/neko-mind.git" }
```
